# Quantization-aware presenter replay

Follow-up to the rejected float-to-int8 replay candidate. This is **head-only
quantization-aware training on a frozen, calibrated PT2E backbone**, not
whole-network QAT or hardware evidence.

- Inputs: the same 151 camera TRAIN / 42 development VAL assignments; old
  A/L/Y TRAIN retained, all 90 reviewed continuous frames included.
- Backbone features are generated by the rejected candidate's real serialized
  quantized graph, including its activation rounding. Only the final classifier
  is replaced during fitting. Class order and original checkpoint/graph hashes
  are verified before extraction.
- Head simulation includes per-channel signed-int8 weight rounding, int32 bias
  rounding with input-scale × weight-scale, and signed-int8 output rounding.
  Straight-through gradients fit the float master weights. A pre-fit check must
  match the untouched PT2E graph on an actual image to max difference <=1e-4.
- Output observer ranges are refreshed **only** on the same 151 camera TRAIN +
  ten/class selected Kaggle TRAIN calibration rows. Calling the head on VAL
  cannot change observer ranges. The display threshold remains 0.80.
- Fast rehearsal: 120 Kaggle TRAIN/class (3,000 frames); same seeded class/split
  selection. No dataset-test predictions. Camera gets one augmented view.
- 90% class-balanced camera / 10% Kaggle sampling, 8,192 samples/epoch, 60 epochs,
  Adam 0.0001. All head rows may adapt to quantization. A logit-preservation loss
  (MSE weight 2) uses only the original 61 legacy TRAIN images.
- Selection uses quantized-feature development metrics with the same A>=3/6,
  L>=5/7, Y>=3/6 floors and aggregate nonregression. These are development
  checks, not fresh-pose accuracy. A fresh full PT2E export must pass separately
  before any firmware build/package.

Training: `.work/asl/quant-replay-train-v2/`. The first attempt stopped before
fitting because the exported graph's pytree output specification removed the
batch dimension. The extractor now preserves the original tuple convention,
checks feature shape explicitly, and has a small exported-graph regression test.

```bash
OMP_NUM_THREADS=2 .work/inference/venv/bin/python -B -m ml.asl.quant_replay \
  --output .work/asl/quant-replay-train-v2
OMP_NUM_THREADS=1 .work/inference/venv/bin/python -B -m ml.asl.replay_export \
  --checkpoint .work/asl/quant-replay-train-v2/best.pth \
  --output .work/asl/quant-replay-export-v1
python3 -B -m tools.replay_asl build --experimental --layout hp-only-large \
  --export .work/asl/quant-replay-export-v1 --jobs 1
```

Existing exports, captures and fallback packages are not overwritten. Training
or simulation success alone does not authorize flashing. No agent-run serial
access or flash is part of this workflow.

## Result: A still fails; no model released

The completed 60-epoch second attempt produced **no eligible checkpoint**.
Final-epoch quantized-feature development displays: **A 2/6, L 5/7, Y 3/6**;
overall **14/30 correct**, one wrong letter, zero negative false letters.
L recovered its required count, but A never exceeded 2/6 in any epoch. Thus the
required A>=3/6 floor still fails. The lowest-loss epoch (8) was also ineligible
(A 2/6, L 4/7, Y 3/6). No threshold or acceptance floor was relaxed.

**No checkpoint, new export, firmware or flash package released. Nothing flashed.**
517 tests pass; 2,934 protected captures/artifacts remain unchanged. Head simulation
was independently checked on all 42 old validation images against the original
PT2E graph: max logit difference 0.0, without observer updates. These numerical
checks validate the simulation, not gesture accuracy.

Evidence: `.work/inference/quant-replay-final-status-v1.json`,
`.work/inference/quant-replay-head-equivalence.json`, and
`.work/asl/quant-replay-train-v2/history.json`. Further head fitting on this small
old A training set has not recovered the missing example; no claim is made that
another retry will solve it. A-focused new session data or a separately scoped
backbone-adaptation experiment is the next step, not another unverified flash.
